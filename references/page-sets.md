# 成套页面结构

依据本次培训转录2第64–65、75–82、106行，每套至少3张，不设置3–4张上限；介绍通常5张。用户若明确指定不同页数，按其要求调整，并说明与培训结构的差别。保留该套模板视觉语言，缺失源工程的新增页注明为同风格延展。

| 类型 | 页面分工 | 图片一致性 |
| --- | --- | --- |
| 推荐、盘点 | 封面总览＋至少2张条目详情；6/9/12/16条按已有合适模板容量扩展详情，不改原布局塞入过多项目 | 封面横向阅读顺序与详情、正文一致；条目详情不重复，同组素材风格一致 |
| 对比 | 两对象封面＋营养/相关字段详情＋适用场景、选择等详情，至少3张 | 同对象照片跨页一致，两对象身份和左右位置一致 |
| 介绍 | 1封面＋1功效/营养详情＋3张包含该食材的不同食谱，共5张 | 前两页照片不同；三张食谱实拍风格协调，小标题字号样式位置一致 |
| 固定搭配、测评 | 原模板的封面和详情分工；至少3张，按内容展开 | 保留各自原模板，测评不得虚构体验 |

介绍食谱必须实际包含所述食材，并符合query的人群与饮食场景；成品菜出现在食谱页，不能替代前两页的食材介绍。食谱图去除多余白边但不裁断菜品，标题置于模板允许的中间或上方。所有食谱均在正文介绍。原禁忌页需要保留时可增加页，不因此删除3张食谱或编造禁忌。
